React library for visual HTML editing: element tree, canvas and Tailwind style panel. It takes an
HTML string, the user edits it, and it returns an HTML string.

<EditorDemo scenario="default" />

## What it is

- **A string in, a string out.** `defaultValue` takes HTML, `onChange` and `getHtml()` give it
  back. Nothing from the editor — ids, overlays, indicators — reaches the output.
- **Panels you compose.** Layers, canvas, inspector and palette are independent roots. Without
  children each renders its default composition; with children you choose the parts, their order
  and their labels.
- **Headless underneath.** Every part is a thin view over a hook, and `parseHtml` / `serializeHtml`
  work outside React entirely.
- **Two layout modes.** Normal flow, with controls that edit the page straight on the canvas, and a
  fixed-layout editor for pages whose elements are absolutely positioned.
- **Two skins, shadcn by default.** The [shadcn/ui skin](/docs/shadcn-skin) is the one to reach
  for: a top bar, a sidebar that merges layers and palette, a canvas with a floating dock and the
  style inspector. The built-in chrome, self-contained in one stylesheet, is there for an app that
  is not on shadcn/ui.
